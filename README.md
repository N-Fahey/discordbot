# Discord Bot

A multi-feature Discord bot built with Python, featuring games, utilities, AI and audio features.  
*This bot is built for a specific server and not intended for general use*

## Features
- Classic games: Connect4, Liars Dice, Russian Roulette, Slots
- Currency system and lobby management
- AI-powered responses and general chat utilities
- Audio bites and YouTube integration
- Admin and event handling tools

## Getting Started
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Configure your settings in `settings.yaml`.
4. Complete the `.env` file with required environment variables (e.g., Discord bot token).
5. Run the bot: `python discordbot.py`

## Requirements
- Python 3.12+
- Discord.py and other dependencies in `requirements.txt`
